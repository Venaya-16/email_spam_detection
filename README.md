# Email Spam Detection using Machine Learning

## Overview

This project implements an email spam detection system using Natural Language Processing (NLP) and Machine Learning. It classifies emails as **Spam** or **Ham (Not Spam)** by preprocessing text data and training a Multinomial Naive Bayes classifier.

## Features

- Text preprocessing and cleaning
- Tokenization and stemming
- Stop-word removal
- TF-IDF vectorization
- Spam classification using Multinomial Naive Bayes
- Prediction on new email messages

## Tech Stack

- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn
- Matplotlib

## Workflow

1. Load and clean the dataset
2. Remove duplicates and preprocess text
3. Convert text into TF-IDF vectors
4. Train a Multinomial Naive Bayes classifier
5. Evaluate the model using classification metrics
6. Predict whether new emails are spam or ham
